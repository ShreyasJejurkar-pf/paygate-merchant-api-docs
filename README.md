# Paygate Merchant API docs (draft)

Draft API reference for the Paygate merchant endpoint, `POST /api/Process/Request`, shared for feedback.

`openapi.json` is generated by the Gateway API's merchant Swagger document. `index.html` renders it with [Scalar](https://github.com/scalar/scalar).
